# OnBai — Apple-inspired redesign

This repository is a static GitHub Pages site. The project path is configured for:

`https://nguyenthevinh04112013-cmd.github.io/onbai-modern-draft-v2/`

## Deploy

1. Keep the repository branch as `main`.
2. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Upload the contents of this archive to the repository root, preserving the `subjects/` and `.github/workflows/` folders.
4. Commit the changes and wait for the **pages build and deployment** workflow to finish with a green check.

## Notes

- All original subject JSON files are retained unchanged.
- Theme, accent, text size, motion, accessibility, default start screen, warning, navigation, and update-notification preferences are stored locally in the browser.
- Reset Settings only resets preferences; it does not erase quiz progress or subject data.
- The design supports desktop and mobile layouts and respects the operating system's reduced-motion preference unless the user overrides it.
